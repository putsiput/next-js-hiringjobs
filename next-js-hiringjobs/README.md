# 🚀 Hiring Jobs (.ai)

> Platform pencari kerja cerdas berbasis kecerdasan buatan (AI) yang dirancang untuk menghubungkan minat dan bakat unik Anda dengan lowongan pekerjaan impian secara presisi.

---

## 🌟 Tentang Proyek

**Hiring Jobs** adalah aplikasi web modern berbasis Next.js yang dikembangkan untuk mengeliminasi ketidaksesuaian penempatan kerja. Menggunakan algoritma pemetaan bakat berbasis AI, platform ini secara otomatis menganalisis profil pengguna dan menyelaraskannya dengan lowongan pekerjaan terbaik dari berbagai sumber global, termasuk integrasi langsung dengan **LinkedIn**.

## ✨ Fitur Unggulan

* **🤖 Analisis Minat & Bakat AI**: Memetakan skill pengguna (seperti *Frontend Development*, *UI/UX Design*, dan *Problem Solving*) secara akurat.
* **⚡ Integrasi Lowongan LinkedIn**: Menemukan dan menyaring lowongan pekerjaan yang paling relevan dengan tingkat kecocokan (*match score*) tinggi.
* **📊 Dashboard Pelamar Pintar**: Memantau status lamaran aktif, undangan interview, dan statistik verifikasi skill.
* **📱 Desain Responsif & Futuristik**: Dibangun dengan antarmuka bertema gelap (*dark mode tech-startup*) yang elegan menggunakan Tailwind CSS.

---

## 🛠️ Tech Stack

* **Framework**: [Next.js](https://next.js5.org/) (App Router)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **Bahasa**: TypeScript / JavaScript
* **Ikon & Visual**: Modern CSS Gradients & Unicode Icons
